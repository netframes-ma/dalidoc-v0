# AGENTS.md — AI Coding Agent Rules

For Claude Code, Codex, Cursor, Qwen Code, or any AI coding assistant.

## Before Editing

1. Inspect the repository.
2. Read relevant docs.
3. Produce a short plan.
4. Implement small changes.
5. Run checks.
6. Report changed files and risks.

## Required Reading

- `README.md`
- `docs/START_HERE.md`
- `docs/BEGINNER_GUIDE.md`
- `docs/ARCHITECTURE.md`
- `docs/TASKS.md`
- `docs/CODING_STANDARDS.md`

## Rules

- Do not rewrite the whole app without approval.
- Use TypeScript, Tailwind, and shadcn/ui.
- Keep components small and typed.
- Use route/controller/service/repository on backend.
- Enforce permissions on backend.
- Preserve clinical history.
- Do not expose sensitive data.
- Do not add treatment details to external calendars.
- Update docs when behavior changes.
