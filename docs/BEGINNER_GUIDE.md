# Beginner Guide

## Purpose

This guide is for a fullstack developer in a learning phase.

## First Week Plan

### Day 1 — Product

Read `README.md`, `START_HERE.md`, and `PRODUCT_REQUIREMENTS.md`.

### Day 2 — Frontend

Learn React, Next.js, Tailwind, and shadcn/ui. Build a simple card.

### Day 3 — Backend

Learn Fastify, Prisma, PostgreSQL. Build one test route.

### Day 4 — Static UI

Build `PatientCard`, `StatusBadge`, and a mock Patients page.

### Day 5 — API Integration

Create `GET /api/patients` and display results in the frontend.

### Day 6 — Form

Create a New Patient form with React Hook Form and Zod.

### Day 7 — Review

Refactor, run checks, update docs, open a PR.

## First PR Suggestion

```txt
feat(ui): add app shell and shared layout components
```

Include sidebar, topbar, page header, status badge, and empty state.

## Mistakes to Avoid

- Coding without reading specs
- Putting everything in one file
- Ignoring loading/error/empty states
- Hardcoding statuses/colors/routes
- Trusting frontend permissions
- Deleting clinical history
- Not running checks
