# Coding Standards

## General

Use TypeScript, clear names, small files, typed props, and validation.

## Frontend

Use Tailwind and shadcn/ui. Keep API calls outside presentation components. Add loading/error/empty states.

## Backend

Use route/controller/service/repository. Enforce clinic scoping and permissions.

## Naming

Components: `PatientCard.tsx`.

Hooks: `usePatients.ts`.

Feature folders: `dental-chart`, `treatment-plans`.

API files: `patients.api.ts`.
