# Roadmap

## Phase 0 — Setup

Docs, project setup, local environment, frontend skeleton, backend skeleton.

## Phase 1 — UI Foundation

App shell, shared components, design tokens, empty/loading/error states.

## Phase 2 — Patients

Patient list, form, profile, medical alerts.

## Phase 3 — Agenda

Weekly calendar, appointment cards, appointment form, statuses.

## Phase 4 — Odontogram

Oval arch, tooth component, selected tooth drawer, assistant draft, dentist validation.

## Phase 5 — Treatment Plans and Billing

Treatment plan builder, invoices, payments.

## Phase 6 — Prescriptions and Communication

Prescription flow, WhatsApp templates, message logs.

## Phase 7 — Calendar

Provider abstraction, Google/Outlook placeholders, ICS fallback.

## Phase 8 — Security and Pilot

RBAC, audit logs, tests, backups, deployment.
