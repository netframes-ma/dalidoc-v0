# Start Here

DaliDoc is a Moroccan dental clinic SaaS MVP.

## Build Order

```txt
App shell → Shared UI → Patients → Agenda → Odontogram → Treatment plans → Billing → Prescriptions → WhatsApp → Calendar → Security/QA
```
